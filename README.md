# 屏幕测量工具箱

把屏幕变成一把可校准的尺子，并支持折线、画笔描边、角度、面积、圆形等多种测量。
依据本目录功能说明文档与原型，重做为**两个一致实现**。

## 交付物

| 文件 | 说明 | 怎么运行 |
|---|---|---|
| `screen_measure.py` | **原生桌面版**（PySide6，推荐） | `pip install PySide6` 后 `python screen_measure.py` |
| `原型.html` | **浏览器原型版**（纯 HTML+Canvas，单文件无依赖） | 双击用浏览器打开 |
| `SPEC.md` | 接口规范（两版共用的数据结构/算法/状态机/右键菜单契约） | 阅读 |
| `_test_algos.py` | 核心算法自测脚本 | `python _test_algos.py` |

## 功能

- **直尺**：选中即在画布生成一把带 mm/cm 刻度的真尺子；拖尺身平移、拖黄端改长、拖绿点旋转；可用银行卡 8.56cm 校准 DPI。
- **折线**：连续点画多条，双击固化当前条接下一条；右键可「继续绘制」「把多段连成一段」、进编辑改形。
- **画笔描边**：按住沿边缘画一笔松手固化，可连续多笔；曲线用 Catmull-Rom 穿过**稀疏锚点**。
- **角度**（3点）/ **面积**（多边形，鞋带公式）/ **圆**（3点拟合）。
- **DPI 校准**：贯穿所有模式，换算 cm。

## 针对本次 4 点要求的实现

1. **直尺=画完线生成一把尺子**：选直尺模式即在画布生成刻度尺，可拖动/旋转/改长（非两点画线）。
2. **折线曲线同 PS：起点与节点连到一起即结束**：逐点点击连线，双击（或连回起点）固化成一条，接着画下一条。
3. **菜单可「继续画」+「把几段连成一段」**：右键菜单含「继续绘制」；「把多段连成一段」按端点最近原则把多条折线贪心串接为一条。
4. **曲线编辑=自己点两个点生成控制点，不自动铺密集节点**：描边固化只按累积距离每约 24px 取一个稀疏锚点；编辑时在曲线上点两点插锚点、拖锚点调形，绝不自动生成一堆密密麻麻节点。

## 验证状态

- PySide6 版：`py_compile` 通过；核心算法自测 **26/26 passed**（面积/样条长/拟合圆/夹角/折线merge/单位换算/点到线段/描边抽稀）；GUI 实例化与六模式切换正常。
- HTML 原型版：HTML 标签闭合配平；提取 `<script>` 经 `node --check` 语法通过；右键菜单项与抽稀逻辑与桌面版一致。
- 两版抽稀逻辑核对一致（沿轨迹累积距离，约 24px 一个锚点）。

## 第二轮改动（4 点）

1. **切换测量模式时询问是否清空画布**：画布有内容时弹确认框——确定=清空全部测量后进入新模式，取消=保留现有测量进入新模式。
2. **去掉状态栏**：删除桌面版画布左下角常驻提示文字、删除原型版底部常驻 `#toast` 状态条；右下角结果面板保留。
3. **切换模式自动回到绘制态**：任何模式切换后 `measureState` 强制为 `draw`，并同步状态段按钮高亮。
4. **画笔描边支持"把多段连成一段"**：每笔曲线重采样成密集点 → 端点最近贪心串接 → 重新平滑抽稀为稀疏锚点，合并为一条，绝不产生密集节点；折线/描边两态右键菜单均含该项。

> 修正说明：首轮子代理曾把弹窗做成"取消则不切换、确定也不真正清空"，与"是否清空"语义不符；已统一为"模式总是切换（对应第3点），弹窗仅决定是否清空画布"。

## 第三轮改动

- **角度可编辑**：角度固化后，左键点住三个顶点（边点/顶点/边点）任一即可拖动改形，夹角实时刷新；点空白不误触，清除仍走右键菜单。两版一致。
- **圆模式点击可见**：采集时每点一个可见点+预览辅助线，固化后三个取样点保留显示。
- **模式使用说明横幅**：画布顶部常驻显示当前模式"怎么用"的说明（切模式/切状态自动更新），两版一致。
